# 🤖 My AI Agent

I'm learning how AI agents work by building my own AI agent from scratch.

This repository documents my journey from understanding the fundamentals to building a functional AI agent.

## 🎯 Goal

Build an AI agent that can:

* Understand user instructions
* Reason about tasks
* Use tools
* Retrieve information
* Remember relevant information
* Take actions
* Complete multi-step tasks
